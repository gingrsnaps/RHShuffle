# RedHunllef V15

V15 introduces one public terminology system, a compact RedPoints Games dashboard, dialog-based profile and recovery tools, matching provider presentation, and Eastern-time calendar editors for both leaderboard providers.

## Scheduling

Shuffle calendar values are authoritative and continue through the existing review/publish transaction. EmpireDrop shows provider dates from the selected slug and separately saves the website display window; official standings remain provider-authoritative.

## Gaming

The Community Leaderboard is visible before profile creation. Profiles and recovery open in focused dialogs. The existing wallet, receipts, fairness verification, public privacy allowlist, ETag handling, and five-second visible-tab polling remain unchanged.
