# Start here — RedHunllef V19

1. Keep the repository private; the package contains production credentials.
2. Export the newest private recovery checkpoint from the live site.
3. Extract the package contents directly into the repository root.
4. Leave the DigitalOcean custom Build Command blank.
5. Run with `python wager_backend.py` on port `8080`.
6. Keep `RH_SPACES_ENABLE=0` unless Spaces is intentionally configured.
7. Use **Force Rebuild and Deploy**.
8. Confirm `/` opens Shuffle and `/?provider=empiredrop` opens EmpireDrop.
9. Test public and administrator pages on a phone-sized viewport.
10. Confirm current race dates, published prizes, RedPoints wallets and administrator accounts.
