# Start here — RedHunllef V18

1. Keep the repository private; the package contains production credentials.
2. Extract the package contents into the repository root.
3. Keep the DigitalOcean custom Build Command blank.
4. Run with `python wager_backend.py` on port `8080`.
5. Set `RH_SPACES_ENABLE=0` unless DigitalOcean Spaces is intentionally configured.
6. Use **Force Rebuild and Deploy**.
7. Open EmpireDrop Prizes and confirm the status is **Published** with a `$2,000.00` public pool.
8. Confirm the public Top 10 shows the advertised prize values.

Export the current private recovery file before replacing a live deployment.
